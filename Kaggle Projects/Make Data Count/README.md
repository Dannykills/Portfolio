# 🗺️ Make Data Count -- Dataset Citation Extraction Notebook

## Overview

This notebook extracts dataset citations from scientific articles (PDF
and XML) and classifies them as **Primary** or **Secondary**.

It includes robust fallback logic, structured outputs, and GPT-based
classification with retry handling.

------------------------------------------------------------------------

## 🔍 Data Extraction

-   Extract PDF text using `langchain` (`PyPDFLoader`)
-   Fallback to XML when PDF text is missing or insufficient
-   Extract:
    -   `https://doi.org/...`
    -   Accession IDs from article body
-   Parse `<ext-link>` elements in XML (with namespace support)
-   Filter DOIs using trusted dataset prefixes
-   Apply token-aware XML truncation for LLM input

------------------------------------------------------------------------

## 🧠 Classification (Primary vs Secondary)

-   Extract local context around each citation
-   Use GPT to classify each dataset as:
    -   **Primary** -- dataset generated by authors
    -   **Secondary** -- dataset reused from external sources
-   Store classification results with associated `type`
-   Skip or log entries if classification fails
-   Implement retry logic with exponential backoff for rate limits

------------------------------------------------------------------------

## 🧾 Structured Output

Each processed article produces structured output:

    {
      "filename": "article_id.pdf",
      "dois": [...],
      "accession_ids": [...],
      "citations": [
          {
            "dataset_id": "...",
            "type": "Primary" | "Secondary"
          }
      ]
    }

------------------------------------------------------------------------

## 📄 Article Handling Logic

-   Attempt PDF extraction first
-   If unsuccessful, fallback to XML
-   Use:
    -   `<ext-link>` parsing
    -   XML-based LLM fallback for dataset inference
-   Skip articles if both methods fail (with logging)

------------------------------------------------------------------------

## ⚙️ Runtime Safeguards

-   GPT retry logic
-   Exponential backoff for rate limiting
-   In-memory storage of structured outputs for downstream processing
